# GoodJob 自动营销系统前端

当前仓库分支仅保留已确认的前端演示版本，不包含后端服务。

## 当前范围

- 多模块自动营销系统桌面端布局
- 获客中心、社媒对话、私域客户池与成交工作台等演示模块
- 智能体与自动脚本均为前端模拟展示
- 深色玻璃质感 UI、荧光绿色强调色与可滑动项目卡片
- Mac 与 Windows 桌面端界面演示

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5188/#acquisition`，点击登录按钮即可进入前端演示系统。

## 验证

```bash
npm test
npm run test:e2e
npm run build
```

该版本不会连接抖音、小红书、快手、微信或微博，也不会执行真实营销任务。
